# Security

This portfolio has no login, payment flow, database or contact-form backend. It links to separate demo applications with their own security boundaries.

Do not submit secrets or private personal information in public issues. Use GitHub's private vulnerability reporting if enabled on this repository. Otherwise open a public issue containing only a minimal non-sensitive request for a private reporting channel; do not disclose exploit details or credentials there.

Dependencies are locked in package-lock.json. CI checks types, lint, tests, build and tracked publication content. Automated scanning and accessibility checks have limits and do not constitute a security audit or accessibility certification.
