# Contributing

Use Node 22.19+ (22.x), npm and a feature branch. Keep Spanish and English content complete and consistent. Add only verified personal information, source-backed project claims and authorized assets.

Run formatting, lint, typecheck, Vitest, production build, Playwright and the publication scan before a pull request. Explain the user-facing change and the checks actually performed. For UI changes include real desktop/mobile screenshots and review keyboard/reduced-motion behavior.

Never commit credentials, local environment files, generated builds, private contact details or data copied from unrelated projects. See SECURITY.md for reporting a vulnerability.
