## FlowTeam (project 03)

Verified owner-supplied sources: [portfolio material](https://github.com/cristoferdiazalvarez/flowteam/blob/main/docs/PORTFOLIO.md), [live HTTPS demo](https://flowteam-ten.vercel.app), [source](https://github.com/cristoferdiazalvarez/flowteam).

Source commit: `70dd9f5d934dae50d8c003618e02a7c3a94cbc27`. All four source PNGs were published under `docs/screenshots/production` in that commit. No files were written to the FlowTeam checkout/repo. `scripts/import-flowteam-assets.mjs` downloads public bytes and reuses Next.js’s Sharp encoder; `flowteam-assets.json` records every URL, SHA-256, dimension, size and transformation.
